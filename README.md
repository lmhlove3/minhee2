# 기사 프로젝트 노트

기사 프로젝트의 진행 상황을 한 페이지에 정리하는 노트입니다. HTML 파일 하나로 되어 있어 설치나 빌드 없이 바로 열 수 있습니다.

## 프로젝트

- 프로젝트 한 줄: [브리프 한 줄]
- 팀: [팀 이름]
- 대주제: 경제

## 구성

| 칸 | 내용 |
|---|---|
| 프로젝트 한 줄 | 프로젝트를 한 문장으로 적는 칸 |
| 팀 이름과 역할 | 팀 이름과 내 역할 |
| 주제 | 대주제(경제)와 내 앵글(현재 "내일 정함") |
| 할 일 체크리스트 | 5개 항목, 체크하면 취소선 표시 |
| 날짜별 기록 | 11/18부터 하루 한 줄, 버튼으로 다음 날짜 추가 |

개인정보(전화번호, 주소 등)를 적는 칸은 없습니다.

## 사용 방법

1. 저장소를 내려받거나 `기사-프로젝트-노트.html` 파일만 저장합니다.
2. 파일을 브라우저(PC·휴대폰)에서 엽니다.
3. 각 칸에 내용을 적습니다.

입력한 내용은 사용하는 브라우저의 로컬 저장소에 자동 저장됩니다. 서버로 전송되지 않으며, 브라우저나 기기를 바꾸면 보이지 않습니다.

## 참고

- 휴대폰 화면에 맞춰 칸이 세로로 정렬됩니다.
- 기기의 다크 모드 설정을 따릅니다.
- 외부 라이브러리나 네트워크 요청이 없습니다.
